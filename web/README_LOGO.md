# Hướng Dẫn Thêm Logo

## Cách thêm logo vào giao diện:

1. **Đặt file ảnh logo** vào thư mục `web/` với tên `logo.png`
   - Hoặc đổi tên file ảnh của bạn thành `logo.png`
   - Copy file vào thư mục: `web/logo.png`

2. **Định dạng ảnh được hỗ trợ:**
   - PNG (khuyến nghị - có nền trong suốt)
   - JPG/JPEG
   - SVG

3. **Kích thước khuyến nghị:**
   - Chiều rộng: 200-400px
   - Tỷ lệ: vuông hoặc gần vuông

4. **Nếu logo không hiển thị:**
   - Kiểm tra tên file đúng: `logo.png`
   - Kiểm tra file nằm trong thư mục `web/`
   - Mở Console trình duyệt (F12) để xem lỗi

Giao diện sẽ tự động ẩn logo nếu không tìm thấy file!
