# Nhom11_LapTrinhMang

## Mô tả dự án
Mục tiêu là xây dựng và minh họa các ví dụ về giao tiếp client-server sử dụng nhiều ngôn ngữ lập trình khác nhau (C++, C#, Go, Java, Python). Dự án tập trung vào việc thực hành các kỹ thuật lập trình socket, tối ưu hóa giao thức TCP, và so sánh hiệu năng giữa các ngôn ngữ. Ngoài ra, nhóm còn thực hiện các bài toán tối ưu hóa truyền dữ liệu, kiểm soát tắc nghẽn, và minh họa các giải pháp TCP hiện đại.

## Hướng dẫn sử dụng
- Mỗi thư mục chứa mã nguồn cho từng ngôn ngữ.
- Để chạy thử, vào thư mục tương ứng và thực hiện theo hướng dẫn trong từng file hoặc sử dụng lệnh phù hợp với ngôn ngữ đó.

## Cấu trúc thư mục
- C++/: Mã nguồn client và server bằng C++
- CSharp/: Mã nguồn client và server bằng C#
- GO/: Mã nguồn client và server bằng Go
- Java/: Mã nguồn client và server bằng Java
- Python/: Mã nguồn client và server bằng Python
